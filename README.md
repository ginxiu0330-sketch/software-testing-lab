# 软件测试实验

本仓库为「软件测试」课程实验作业，同时用于练习 GitHub 协作流程。

## 仓库内容

| 文件 | 说明 |
| --- | --- |
| 实验报告.md | 实验报告正文（步骤记录、证据链接、自查表） |
| hello.py | 用于 Fork + PR 环节演示改动的示例代码 |

## 协作流程（本仓库演示）

1. 在共享仓库中从 main 拉出特性分支
2. 修改并提交，向 main 发起 Pull Request
3. 组长 / 指定同学 Code Review 后合并
4. 另一条链路：Fork 他人仓库 -> 修改 -> 向上游发起 PR -> 上游审核合并

## 状态

- 仓库可见性：Public（组员与老师可直接访问）
- 首个提交：实验报告 + 示例代码
